# Sol signature reference

Canonical visual reference files:

- `Sol-reference.png` — transparent visual reference.
- `Sol-reference.psd` — editable archival reference.

## Mandatory usage rule

These reference files are **never pasted, placed, imported, composited, or reused as
finished signature pixels** in an artwork. They exist only so the artist can look at
the established handwriting.

At the end of each finished artwork, redraw `Sol` manually with Photoshop brush
strokes on its own layer. Match the reference as closely as practical, but use the
minimum number of natural, continuous hand-signing gestures rather than mechanically
tracing its pixels with many small segments. Slight variation is desirable because
each work should look freshly signed rather than stamped.

Paint the finalization date by brush at the same time, not with a text layer, and keep
the date quieter than the signature.

If a previously signed work is reopened for substantive artistic changes, treat the
existing signature/date as provisional. Re-review and, where appropriate, redraw the
signature and date only after the new artistic work is finished, then make the new
final exports.
